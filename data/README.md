Download [US Accidents (2016–2023)](https://www.kaggle.com/datasets/sobhanmoosavi/us-accidents) (`US_Accidents_March23.csv`) into this folder, then run:

```bash
python ../pipeline/01_clean.py
python ../pipeline/02_filter_california.py   # -> CA_Accidents_Main.csv
```
